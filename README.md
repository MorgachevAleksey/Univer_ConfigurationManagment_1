# Эмулятор командной оболочки UNIX (Вариант №16)

## 1. Общее описание
Данный проект представляет собой эмулятор командной оболочки (Shell) для UNIX-подобных операционных систем.
Эмулятор реализован на языке Java с использованием графического интерфейса (Swing).
Проект разрабатывается в рамках дисциплины "Конфигурационное управление".

## 2. Описание всех функций и настроек
На данный момент (Этап 1) реализованы следующие функции:
*   **Графический интерфейс (GUI):** Окно терминала с полем ввода и областью вывода.
*   **Динамический заголовок окна:** Формируется на основе реальных данных ОС в формате `Эмулятор - [username@hostname]`.
*   **Парсер:** Поддерживает разбиение строки на команду и аргументы, а также раскрытие переменных окружения реальной ОС (например, `$HOME`).
*   **Команды-заглушки:**
    *   `ls` — выводит свое имя и переданные аргументы.
    *   `cd` — выводит свое имя и аргументы (с проверкой на наличие аргументов).
*   **Служебная команда:**
    *   `exit` — завершает работу эмулятора.
*   **Обработка ошибок:** Вывод сообщений о неизвестных командах и неверных аргументах без падения программы.

## 3. Команды для сборки проекта и запуска тестов
Для сборки проекта используется система Gradle.
*   **Сборка проекта:** `./gradlew build` (или `gradlew.bat build` на Windows)
*   **Запуск проекта:** `./gradlew run` (или `gradlew.bat run`)
*   **Запуск тестов:** `./gradlew test`

## 4. Примеры использования
1. Запустите проект командой `gradlew run`.
2. В открывшемся окне введите:
    *   `ls -la` -> Вывод: `ls: name=ls, args=[-la]`
    *   `cd /tmp` -> Вывод: `cd: name=cd, args=[/tmp]`
    *   `cd` -> Вывод: `Error: cd: missing operand`
    *   `unknown_cmd` -> Вывод: `Command not found: unknown_cmd`
    *   `ls $HOME` -> Вывод: `ls: name=ls, args=[/home/user]` (путь зависит от вашей ОС)
    *   `exit` -> Приложение закрывается.
