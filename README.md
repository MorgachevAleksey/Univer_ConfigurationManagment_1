# Эмулятор оболочки — вариант 16, этап 1

Приложение на Java Swing принимает команды и отображает результат.
Заголовок окна содержит реальные имя пользователя и имя компьютера.

Команды: ls и cd выводят своё имя и аргументы, exit закрывает приложение.
Поддерживаются переменные окружения $VAR, включая подстановку внутри пути.
Неизвестная команда вызывает сообщение об ошибке.
Параметров запуска на первом этапе нет.

Требуется JDK 17 или новее.

Сборка: `.\gradlew.bat build`
Тесты: `.\gradlew.bat test`
Запуск: `.\run.bat`

Примеры ввода: `ls -la`, `cd /tmp`, `cd`,
`ls $USERPROFILE/docs`, `unknown_cmd`, `exit`.
